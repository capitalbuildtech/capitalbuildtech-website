# Capital BuildTech Engineering Website

Production-ready React/Vite corporate website for Capital BuildTech Engineering.

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Stack

- React
- React Router
- Framer Motion
- Lucide React
- Tailwind CSS
- Vite
